# Moments

A cross-platform Flutter journaling application for capturing, organizing, and revisiting meaningful moments.

---

## Overview

Moments is a personal journaling application built with Flutter that allows users to create, store, and browse meaningful life moments through a clean and intuitive interface.

The goal of this project was to gain hands-on experience with Flutter development, state management, and building responsive user interfaces while creating an application that feels simple and enjoyable to use.

---

## Features

- Create new journal entries
- Browse saved moments
- View detailed entries
- Responsive Flutter UI
- Cross-platform support
- Clean Material Design interface

## Getting Started

Clone the repository:

```bash
git clone https://github.com/brookes-gonzales/Moments.git
```

Move into the project:

```bash
cd Moments
```

Install dependencies:

```bash
flutter pub get
```

Run the application:

```bash
flutter run
```
